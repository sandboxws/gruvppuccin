# Gruvppuccin

> Warm, ergonomic color palette blending Gruvbox and Catppuccin for editors, terminals, and TUI apps.

## Palette

13 flavors in 4 families, each defining the same 26 semantic roles. The canonical
definition is [`palette.json`](palette.json); every swatch and every port file is
generated from it.

**[→ Full palette reference (all 13 flavors, all 26 roles)](PALETTE.md)**

### Structure

Roles split into a 12-step structural ramp (`crust` → `text`) and 14 accents
(`rosewater`, `flamingo`, `pink`, `mauve`, `red`, `maroon`, `peach`, `yellow`,
`green`, `teal`, `sky`, `sapphire`, `blue`, `lavender`).

Only **5 distinct accent sets** are shared across the 13 flavors. Six accents are
authored per set; the rest are blended from them with a fixed formula, shared with
the sibling `gruvppuccin-vscode`, `gruvppuccin.nvim` and `gruvppuccin-logseq` repos:

```
teal      = lerp(sapphire, green,    0.40)    pink      = lerp(mauve,  maroon, 0.50)
maroon    = lerp(red,      peach,    0.35)    flamingo  = lerp(maroon, peach,  0.50)
lavender  = lerp(mauve,    sapphire, 0.30)    rosewater = lerp(peach,  yellow, 0.40)
sky       = lerp(sapphire, text,     0.30)    blue      = sapphire
```

`lerp` rounds with `floor(x + 0.5)` — a family invariant that keeps byte-parity
across repos. `sky` anchors on each flavor's own `text`, so it is the one accent
that varies within a set. **Nocturne** is the exception to the formula: its accent
slots hold semantically inverted hues (`peach` is a sky blue), so its extended
accents are authored by hand.

```sh
# Read any role from any flavor
jq -r '.flavors.mocha.colors.red' palette.json
jq -r '.flavors | keys[]' palette.json
```

## Contributing

`palette.json` is the single source of truth. Everything under `ports/`, plus
`PALETTE.md` and the palette table above, is generated — **do not edit those by
hand**; edit `palette.json` or the templates in `templates/` and regenerate:

```sh
python3 scripts/generate.py              # regenerate everything
python3 scripts/generate.py --check      # fail if the tree is stale (CI)
python3 scripts/generate.py --validate-palette
python3 scripts/generate.py --list-ports
```

The generator is Python 3 standard library only — no dependencies, no build step.
A pre-commit hook runs it automatically.
